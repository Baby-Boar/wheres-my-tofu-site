# Where's My Tofu!? landing page

Static landing page for the game, served by GitHub Pages: https://baby-boar.github.io/wheres-my-tofu-site/

- `index.html`: the whole page (styles and scripts inline, fonts from Google Fonts).
- `shots/`: in-game screenshots (captured with the game's devctl scenarios).
- `music/tsuyu-drive.ogg`: 4FX - Tsuyu Drive, played by the cassette in the top bar.
- `video/rain.mp4`: the hero clip (night, pouring rain, cockpit view), `video/rain.jpg` its poster.

The Steam link is a placeholder: set `STEAM_URL` at the bottom of `index.html` once the store page exists.
